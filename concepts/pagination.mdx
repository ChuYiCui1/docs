AShareHub V2 does **not** accept `limit` or `offset` parameters. Each endpoint applies a fixed server-side safety cap, and the SDK returns the bounded result as a single `pd.DataFrame`.

This keeps the public contract deterministic and prevents callers from accidentally issuing expensive unbounded scans. To retrieve the data you need, narrow the request with `symbol`, `start_date`, `end_date`, `trade_date`, or the endpoint-specific filters shown on its API reference page.

## Basic Example

Use `YYYYMMDD` dates to request a focused window:

```python
from asharehub import AShareHub

client = AShareHub(api_key="ash_...")

df = client.market_daily(
    symbol="000001.SZ",
    start_date="20240101",
    end_date="20241231",
)
print(df[["trade_date", "open", "high", "low", "close", "vol"]])
```

For a cross-sectional query, prefer an exact `trade_date`:

```python
snapshot = client.fundamentals(trade_date="20240603")
```

## Splitting Large Histories

If a broad request reaches the server cap, split it into non-overlapping date windows rather than using offsets:

```python
import pandas as pd

windows = [
    ("20220101", "20221231"),
    ("20230101", "20231231"),
    ("20240101", "20241231"),
]

frames = [
    client.market_daily(symbol="600519.SH", start_date=start, end_date=end)
    for start, end in windows
]
history = pd.concat(frames, ignore_index=True).drop_duplicates(
    subset=["symbol", "trade_date"]
)
```

For financial statements, split by reporting periods or use the exact `period` filter:

```python
annual = client.income(symbol="000001.SZ", period="20241231")
```

## Reference Endpoints

Bounded reference endpoints such as `stock_list()` and `industry_list()` return their complete current dataset in one call. They support semantic filters instead of pagination:

```python
listed_sse = client.stock_list(exchange="SSE", list_status="L")
industries = client.industry_list()
```

<Warning>
  Raw legacy V1 REST endpoints may still expose `limit` and `offset` for compatibility. Do not pass them to the default V2 SDK methods. All new integrations should use date and semantic filters.
</Warning>

<Tip>
  Every date-window request counts against your API quota. Choose the widest window that stays below the endpoint's fixed row cap, cache completed windows locally, and avoid repeatedly downloading unchanged history.
</Tip>
