The `stock_list()` method returns the complete directory of Chinese A-share stocks listed on the Shanghai (SSE), Shenzhen (SZSE), and Beijing (BSE) exchanges. Each row includes the stock's identity, exchange membership, market tier, industry classification, and listing status. The V2 endpoint returns the bounded reference dataset in one call and supports directory filters instead of pagination.

```python
df = client.stock_list(
    symbol: Optional[str] = None,
    name: Optional[str] = None,
    market: Optional[str] = None,
    list_status: Optional[str] = None,
    exchange: Optional[str] = None,
    is_hs: Optional[str] = None,
) -> pd.DataFrame
```

## Parameters

<ParamField query="symbol" type="str" optional>
  Filter results to a single stock by its suffixed code, e.g. `"000001.SZ"`. Omit to retrieve the full directory.
</ParamField>

<ParamField query="name" type="str" optional>
  Filter by stock name.
</ParamField>

<ParamField query="market" type="str" optional>
  Filter by market segment, such as `主板`, `创业板`, `科创板`, or `北交所`.
</ParamField>

<ParamField query="list_status" type="str" optional>
  Filter by listing status: `L`, `D`, or `P`.
</ParamField>

<ParamField query="exchange" type="str" optional>
  Filter by exchange, such as `SSE`, `SZSE`, or `BSE`.
</ParamField>

<ParamField query="is_hs" type="str" optional>
  Filter by Stock Connect eligibility flag.
</ParamField>

<Note>
  This endpoint does **not** accept `start_date` or `end_date` parameters — it returns current and historical listing records simultaneously, distinguished by `list_status`.
</Note>

## Response Fields

The method returns a `pd.DataFrame` where each row corresponds to one stock. Field definitions follow the `StockBasic` model.

<ResponseField name="symbol" type="str">
  Suffixed stock code, e.g. `"600519.SH"` or `"000001.SZ"`.
</ResponseField>

<ResponseField name="name" type="str">
  Short Chinese stock name, e.g. `"贵州茅台"`.
</ResponseField>

<ResponseField name="area" type="str">
  Province or region where the company is headquartered, e.g. `"贵州"`.
</ResponseField>

<ResponseField name="industry" type="str">
  Broad industry label, e.g. `"白酒"`.
</ResponseField>

<ResponseField name="fullname" type="str">
  Full legal company name in Chinese.
</ResponseField>

<ResponseField name="enname" type="str">
  Full legal company name in English.
</ResponseField>

<ResponseField name="cnspell" type="str">
  Pinyin abbreviation of the Chinese name, e.g. `"GZMT"`.
</ResponseField>

<ResponseField name="market" type="str">
  Market tier. Common values: `"主板"` (Main Board), `"创业板"` (ChiNext), `"科创板"` (STAR Market), `"北交所"` (BSE).
</ResponseField>

<ResponseField name="exchange" type="str">
  Exchange code: `"SSE"` (Shanghai) or `"SZSE"` (Shenzhen).
</ResponseField>

<ResponseField name="curr_type" type="str">
  Trading currency code, typically `"CNY"`.
</ResponseField>

<ResponseField name="list_status" type="str">
  Current listing status: `"L"` = listed, `"D"` = delisted, `"P"` = suspended.
</ResponseField>

<ResponseField name="list_date" type="date">
  Date the stock was first listed on its exchange (`YYYYMMDD`).
</ResponseField>

<ResponseField name="delist_date" type="date">
  Date the stock was delisted, if applicable. `null` for currently listed stocks.
</ResponseField>

<ResponseField name="is_hs" type="str">
  Stock Connect eligibility: `"H"` = Shanghai–Hong Kong Connect, `"S"` = Shenzhen–Hong Kong Connect, `"N"` = not eligible.
</ResponseField>

## Example Usage

The snippet below demonstrates how to page through the entire A-share universe using a `while` loop, collecting all results into a single DataFrame.

```python
from asharehub import AShareHub
client = AShareHub(api_key="ash_...")

# Retrieve the full stock directory in one call
universe = client.stock_list()
print(f"Total stocks retrieved: {len(universe)}")

# Filter to only currently listed stocks on SSE
sse_listed = universe[
    (universe["list_status"] == "L") & (universe["exchange"] == "SSE")
]
print(sse_listed[["symbol", "name", "market", "industry"]].head(10))
```
