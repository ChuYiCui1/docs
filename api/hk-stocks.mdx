---

`hk_stock_list()` returns the Hong Kong security directory. Symbols use a five-digit code plus the `.HK` suffix, such as `00700.HK` for Tencent.

```python
stocks = client.hk_stock_list(list_status="L")
```

REST endpoint: `GET /v2/hk/basic`

## Parameters

<ParamField query="symbol" type="str" optional>
  Exact suffixed symbol, for example `00700.HK`.
</ParamField>

<ParamField query="list_status" type="str" optional>
  `L` for listed, `D` for delisted, or `P` for suspended.
</ParamField>

## Response fields

The response includes `symbol`, `name`, `fullname`, `enname`, `cn_spell`, `market`, `list_status`, `list_date`, `delist_date`, `trade_unit`, `isin`, and `curr_type`.

```python
tencent = client.hk_stock_list(symbol="00700.HK")
print(tencent[["symbol", "name", "trade_unit", "curr_type"]])
```
