sidebarTitle: "HK Trade Calendar"
description: "Query Hong Kong Exchange trading days, holidays, and the previous valid trading date."
---

`hk_trade_calendar()` returns the HKEX calendar independently of the mainland SSE/SZSE calendar.

```python
calendar = client.hk_trade_calendar(
    start_date="20260101",
    end_date="20261231",
    is_open=1,
)
```

REST endpoint: `GET /v2/hk/trade-calendar`

## Parameters

<ParamField query="start_date" type="str" optional>
  Inclusive start date in `YYYYMMDD` format.
</ParamField>

<ParamField query="end_date" type="str" optional>
  Inclusive end date in `YYYYMMDD` format.
</ParamField>

<ParamField query="is_open" type="int" optional>
  `1` for trading days or `0` for closed days.
</ParamField>

The response contains `exchange` (`HKEX`), `cal_date`, `is_open`, and `pretrade_date`.

<Note>
  Hong Kong and mainland holidays differ. Use this endpoint rather than `trade_calendar()` when scheduling `.HK` data jobs.
</Note>
