The `analyst_reports` method returns sell-side analyst earnings forecasts and stock ratings compiled from Chinese brokerage research departments. Each row typically represents one analyst report or consensus estimate entry for a given stock, covering forward earnings projections, target prices, and rating categories. Because the schema can vary by data provider and brokerage source, you should inspect `df.columns` on your first call to discover the exact fields available for your subscription tier before building downstream analysis.

```python
client.analyst_reports(
    symbol: str | None = None,
    start_date: str | None = None,
    end_date: str | None = None,
) -> pd.DataFrame
```

## Parameters

<ParamField query="symbol" type="str" optional>
  Stock code in suffixed format, e.g. `"000001.SZ"`. Omit to retrieve analyst reports across multiple companies for the given date range.
</ParamField>

<ParamField query="start_date" type="str" optional>
  Start of the date range in `YYYYMMDD` format. Typically filters on the report publication date.
</ParamField>

<ParamField query="end_date" type="str" optional>
  End of the date range in `YYYYMMDD` format.
</ParamField>

## Response Fields

The V2 response uses the following public columns:

- Identity and report metadata: `symbol`, `name`, `report_date`, `report_title`, `report_type`, `classify`, `org_name`, `author_name`, `quarter`.
- Forecast metrics: `op_rt`, `op_pr`, `tp`, `np`, `eps`, `pe`, `rd`, `roe`, `ev_ebitda`.
- Rating and price range: `rating`, `max_price`, `min_price`, `imp_dg`, `create_time`.

Calendar-date values such as `report_date` use `YYYYMMDD`. Some metric columns may be null when the source report does not publish that estimate.

## Example

```python
from asharehub import AShareHub

client = AShareHub(api_key="ash_...")

# Fetch recent analyst reports for CATL
df = client.analyst_reports(
    symbol="300750.SZ",
    start_date="20240101",
    end_date="20240331",
)

# Inspect the returned estimates
print("Available columns:", df.columns.tolist())
print(df.head())
```
