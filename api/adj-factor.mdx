---
title: "adj_factor — Daily Price Adjustment Factors"
sidebarTitle: "adj_factor"
description: "Retrieve daily adjustment factors used to compute backward or forward-adjusted historical prices for Chinese A-share stocks after corporate actions."
---

`adj_factor` returns the cumulative price-adjustment multiplier for each trading day of a Chinese A-share stock. Adjustment factors change whenever a corporate action — such as a cash dividend, stock split, rights issue, or bonus share distribution — alters the stock's comparable price series. Combine these factors with the raw OHLCV data returned by [`market_daily`](/api/market-daily) to calculate forward-adjusted (前复权) or backward-adjusted (后复权) prices.

```python
df = client.adj_factor(
    symbol="000001.SZ",
    start_date="20200101",
    end_date="20241231",
)
```

## Parameters

<ParamField query="symbol" type="str" optional>
  Stock code in suffixed format, e.g. `000001.SZ`. Omit to retrieve factors across all symbols.
</ParamField>

<ParamField query="start_date" type="str" optional>
  Start of the date range in `YYYYMMDD` format. Inclusive.
</ParamField>

<ParamField query="end_date" type="str" optional>
  End of the date range in `YYYYMMDD` format. Inclusive.
</ParamField>

<ParamField query="trade_date" type="str" optional>
  Exact trading date in `YYYYMMDD` format.
</ParamField>

## Response Fields

Each row maps to the `AdjFactor` model and represents the adjustment factor effective on one trading day for one stock.

<ResponseField name="symbol" type="str">
  Suffixed stock code, e.g. `000001.SZ`.
</ResponseField>

<ResponseField name="trade_date" type="date">
  Trading date in `YYYYMMDD` format.
</ResponseField>

<ResponseField name="adj_factor" type="float">
  Cumulative adjustment factor for the day. A value of `1.0` means no adjustments have been applied relative to the base date. The factor increases over time as dividends and other distributions accumulate.
</ResponseField>

## Example Usage

```python
from asharehub import AShareHub
import pandas as pd

client = AShareHub(api_key="ash_...")

# Choose the adjustment anchor explicitly. Here T is the last trading day on
# or before 20241231.
daily = client.market_daily(
    symbol="601398.SH", start_date="20200101", end_date="20241231"
)
adj = client.adj_factor(
    symbol="601398.SH", start_date="20200101", end_date="20241231"
)

merged = daily.merge(adj, on=["symbol", "trade_date"], how="inner")
merged = merged.sort_values("trade_date")
anchor_factor = merged.iloc[-1]["adj_factor"]

merged["close_qfq"] = merged["close"] * merged["adj_factor"] / anchor_factor
merged["close_hfq"] = merged["close"] * merged["adj_factor"]

print(merged[["trade_date", "close", "close_hfq", "close_qfq"]].head(10))
```

<Note>
  Let `P(t)` be an unadjusted price and `F(t)` its adjustment factor. Choose an anchor trading date `T`. Use the last trading day on or before your target `end_date`; when you omit `end_date`, use the latest available trading day.

  To compute a **forward-adjusted** price series (前复权), use:

  ```
  qfq(t) = P(t) × F(t) / F(T)
  ```

  This guarantees `qfq(T) = P(T)`. The same historical date can therefore have a different forward-adjusted price when you choose a different anchor.

  To compute a **backward-adjusted** price series (后复权), use:

  ```
  hfq(t) = P(t) × F(t)
  ```

  The `technical_factors` endpoint returns pre-computed `_hfq` and `_qfq` series if you prefer not to calculate these yourself.
</Note>

<Tip>
  Apply the same formulas to `open`, `high`, `low`, and `close`. Do not adjust `vol` or `amount`. Do not use the last row of a truncated response as the anchor unless it is actually date `T`.
</Tip>

<Warning>
  Pre-computed `_qfq` fields are snapshots anchored to the latest trading day available when the source refreshed that record. Calculate from raw daily prices and `adj_factor` when you need a historical anchor or strict reproducibility. Recompute cached forward-adjusted series after a new corporate action or factor correction.
</Warning>
