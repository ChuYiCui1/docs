title: "index_weight — Index Constituent Weights"
sidebarTitle: "Index Weight"

---

The `index_weight()` method returns the constituent stocks of a Chinese equity index along with each stock's weight in that index as of a given trading date. You can use this data to replicate index holdings, measure factor exposure relative to a benchmark, or track historical rebalancing events. The parent index is returned as `symbol`, and each constituent stock is returned as `con_symbol`.

```python
df = client.index_weight(
    symbol: Optional[str] = None,
    start_date: Optional[str] = None,
    end_date: Optional[str] = None,
    trade_date: Optional[str] = None,
) -> pd.DataFrame
```

## Parameters

<ParamField query="symbol" type="str" optional>
  Suffixed index code identifying the index whose constituents you want to retrieve, e.g. `"000300.SH"` for CSI 300 or `"399001.SZ"` for SZSE Component. Returned as `symbol` in the response.
</ParamField>

<ParamField query="start_date" type="str" optional>
  Start of the date range (inclusive) in `YYYYMMDD` format.
</ParamField>

<ParamField query="end_date" type="str" optional>
  End of the date range (inclusive) in `YYYYMMDD` format.
</ParamField>

<ParamField query="trade_date" type="str" optional>
  Exact constituent snapshot date in `YYYYMMDD` format.
</ParamField>

## Response Fields

The method returns a `pd.DataFrame` where each row represents one constituent stock's weight in the index on a given trading date. Field definitions follow the `IndexWeight` model.

<ResponseField name="symbol" type="str">
  Suffixed code of the parent index, e.g. `"000300.SH"`. This is the value passed via the `symbol` parameter.
</ResponseField>

<ResponseField name="trade_date" type="date">
  The date as of which this constituent weight applies (`YYYYMMDD`).
</ResponseField>

<ResponseField name="con_symbol" type="str">
  Suffixed stock code of the constituent, e.g. `"600519.SH"`.
</ResponseField>

<ResponseField name="con_name" type="str">
  Short Chinese name of the constituent stock, e.g. `"贵州茅台"`.
</ResponseField>

<ResponseField name="weight" type="float">
  The constituent's percentage weight in the index, expressed as a value between 0 and 100.
</ResponseField>

## Example Usage

<Note>
  The `symbol` parameter identifies the parent index, and the response echoes it as `symbol`. Constituent stocks use `con_symbol`.
</Note>

```python
from asharehub import AShareHub
client = AShareHub(api_key="ash_...")

# Retrieve all 300 CSI 300 constituents for the latest available date
csi300_weights = client.index_weight(
    symbol="000300.SH",
)
print(f"Constituents returned: {len(csi300_weights)}")
print(csi300_weights[["con_symbol", "con_name", "weight"]].head(10))

# Verify weights sum to ~100%
total_weight = csi300_weights["weight"].sum()
print(f"Total weight: {total_weight:.2f}%")

# Get historical weights for the SZSE Component around a rebalancing date
szse_hist = client.index_weight(
    symbol="399001.SZ",
    start_date="20240601",
    end_date="20240630",
)
# Identify the most recent snapshot date
latest_date = szse_hist["trade_date"].max()
snapshot = szse_hist[szse_hist["trade_date"] == latest_date]
top10 = snapshot.nlargest(10, "weight")[["con_symbol", "con_name", "weight"]]
print(top10)
```
