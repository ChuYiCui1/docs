`margin` returns daily margin trading statistics for Chinese A-share stocks eligible for the 融资融券 (margin financing and securities lending) programme. Each row covers the outstanding margin-long balance, short-sell balance, margin buy amount, securities returned, and the combined total balance for a stock on a given trading day. This data reflects the aggregate leveraged positioning of retail and institutional participants and is widely used as a sentiment and flow indicator.

```python
df = client.margin(
    symbol="000001.SZ",
    start_date="20240101",
    end_date="20240331",
)
```

## Parameters

<ParamField query="symbol" type="str" optional>
  Stock code in suffixed format, e.g. `000001.SZ`. Omit to retrieve data across all margin-eligible stocks.
</ParamField>

<ParamField query="start_date" type="str" optional>
  Start of the date range in `YYYYMMDD` format. Inclusive.
</ParamField>

<ParamField query="end_date" type="str" optional>
  End of the date range in `YYYYMMDD` format. Inclusive.
</ParamField>

<ParamField query="trade_date" type="str" optional>
  Exact trading date in `YYYYMMDD` format.
</ParamField>

## Response Fields

Each row maps to the `MarginDetail` model and represents one stock's margin trading summary for one trading day.

<ResponseField name="trade_date" type="date">
  Trading date in `YYYYMMDD` format.
</ResponseField>

<ResponseField name="symbol" type="str">
  Suffixed stock code, e.g. `000001.SZ`.
</ResponseField>

<ResponseField name="name" type="str">
  Short Chinese name of the security.
</ResponseField>

<ResponseField name="rzye" type="float">
  **融资余额** — Outstanding margin long balance (total CNY lent by brokers for long purchases), in CNY.
</ResponseField>

<ResponseField name="rqye" type="float">
  **融券余额** — Outstanding short-sell balance (market value of shares borrowed and sold short), in CNY.
</ResponseField>

<ResponseField name="rzmre" type="float">
  **融资买入额** — Margin buy amount for the day (new margin purchases), in CNY.
</ResponseField>

<ResponseField name="rqyl" type="float">
  **融券余量** — Outstanding short-sell volume (shares still on loan), in shares.
</ResponseField>

<ResponseField name="rzche" type="float">
  **融资偿还额** — Margin repayment amount for the day (loans repaid), in CNY.
</ResponseField>

<ResponseField name="rqchl" type="float">
  **融券偿还量** — Short-sell return volume for the day (shares returned to lender), in shares.
</ResponseField>

<ResponseField name="rqmcl" type="float">
  **融券卖出量** — Short-sell sell volume for the day (new shares borrowed and sold), in shares.
</ResponseField>

<ResponseField name="rzrqye" type="float">
  **融资融券余额** — Combined total balance (融资余额 + 融券余额), in CNY. This is the headline margin balance figure.
</ResponseField>

## Example Usage

```python
from asharehub import AShareHub

client = AShareHub(api_key="ash_...")

# Daily margin balance for CITIC Securities over one quarter
df = client.margin(
    symbol="600030.SH",
    start_date="20240101",
    end_date="20240331",
)
print(df[["trade_date", "rzye", "rqye", "rzmre", "rzrqye"]])

# Stocks with the largest margin long balance on a given date
df_all = client.margin(
    start_date="20240603",
    end_date="20240603",
)
top_long = df_all.nlargest(10, "rzye")[["symbol", "name", "rzye", "rzmre", "rzrqye"]]
print(top_long)

# Track net margin flow (buy minus repay) as a momentum signal
df["net_rz_flow"] = df["rzmre"] - df["rzche"]
print(df[["trade_date", "rzye", "net_rz_flow"]])
```

<Note>
  Only stocks on the official margin-eligible list (融资融券标的) appear in this endpoint. The eligible list is updated periodically by SSE and SZSE.
</Note>

<Tip>
  A rising `rzye` (margin long balance) alongside a rising price suggests leveraged conviction; a rising `rzye` with a falling price may indicate trapped longs and potential forced-liquidation risk.
</Tip>
