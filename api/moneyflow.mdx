---
title: "moneyflow — Per-Stock Money Flow by Order Size"
sidebarTitle: "moneyflow"
description: "Get daily money flow broken down by order size (small, medium, large, extra-large) for individual A-share stocks to gauge institutional activity."
---

The `moneyflow` method returns daily buy and sell volumes and amounts for a single stock, segmented into four order-size tiers. Analysts use this breakdown to infer institutional versus retail participation: small orders (under ¥200 k) typically reflect retail activity, while large and extra-large orders (above ¥2 M) are associated with institutional and programmatic trading. The `net_mf_vol` and `net_mf_amount` summary columns give you the overall net money flow without needing to sum individual tiers.

```python
client.moneyflow(
    symbol: str | None = None,
    start_date: str | None = None,
    end_date: str | None = None,
    limit: int = 100,
    offset: int = 0,
) -> pd.DataFrame
```

## Parameters

<ParamField query="symbol" type="str" optional>
  Stock code in suffixed format, e.g. `"000001.SZ"` (Ping An Bank, Shenzhen) or `"600519.SH"` (Kweichow Moutai, Shanghai). Omit to return flows across all stocks for the given date range.
</ParamField>

<ParamField query="start_date" type="str" optional>
  Start of the date range in `YYYY-MM-DD` format. Filters rows where `trade_date >= start_date`.
</ParamField>

<ParamField query="end_date" type="str" optional>
  End of the date range in `YYYY-MM-DD` format. Filters rows where `trade_date <= end_date`.
</ParamField>

<ParamField query="limit" type="int" default={100}>
  Maximum number of rows to return. Defaults to `100`.
</ParamField>

<ParamField query="offset" type="int" default={0}>
  Zero-based pagination offset for iterating through multi-page results.
</ParamField>

## Response Fields

<ResponseField name="ts_code" type="str">
  The stock's Tushare-style code, e.g. `"000001.SZ"`.
</ResponseField>

<ResponseField name="trade_date" type="date">
  Trading date for this record (`YYYY-MM-DD`).
</ResponseField>

<ResponseField name="buy_sm_vol" type="int">
  Buy volume from **small** orders (单笔成交额 < ¥200,000), in lots (手).
</ResponseField>

<ResponseField name="buy_sm_amount" type="float">
  Buy amount from small orders, in CNY 10,000 (万元).
</ResponseField>

<ResponseField name="sell_sm_vol" type="int">
  Sell volume from small orders, in lots.
</ResponseField>

<ResponseField name="sell_sm_amount" type="float">
  Sell amount from small orders, in CNY 10,000.
</ResponseField>

<ResponseField name="buy_md_vol" type="int">
  Buy volume from **medium** orders (¥200,000–¥2,000,000), in lots.
</ResponseField>

<ResponseField name="buy_md_amount" type="float">
  Buy amount from medium orders, in CNY 10,000.
</ResponseField>

<ResponseField name="sell_md_vol" type="int">
  Sell volume from medium orders, in lots.
</ResponseField>

<ResponseField name="sell_md_amount" type="float">
  Sell amount from medium orders, in CNY 10,000.
</ResponseField>

<ResponseField name="buy_lg_vol" type="int">
  Buy volume from **large** orders (¥2,000,000–¥20,000,000), in lots.
</ResponseField>

<ResponseField name="buy_lg_amount" type="float">
  Buy amount from large orders, in CNY 10,000.
</ResponseField>

<ResponseField name="sell_lg_vol" type="int">
  Sell volume from large orders, in lots.
</ResponseField>

<ResponseField name="sell_lg_amount" type="float">
  Sell amount from large orders, in CNY 10,000.
</ResponseField>

<ResponseField name="buy_elg_vol" type="int">
  Buy volume from **extra-large** orders (> ¥20,000,000), in lots.
</ResponseField>

<ResponseField name="buy_elg_amount" type="float">
  Buy amount from extra-large orders, in CNY 10,000.
</ResponseField>

<ResponseField name="sell_elg_vol" type="int">
  Sell volume from extra-large orders, in lots.
</ResponseField>

<ResponseField name="sell_elg_amount" type="float">
  Sell amount from extra-large orders, in CNY 10,000.
</ResponseField>

<ResponseField name="net_mf_vol" type="int">
  Net money flow volume across **all** tiers (total buy vol − total sell vol), in lots.
</ResponseField>

<ResponseField name="net_mf_amount" type="float">
  Net money flow amount across all tiers (total buy amount − total sell amount), in CNY 10,000.
</ResponseField>

<Tip>
  **Order size tiers at a glance:**
  | Tier | Abbreviation | Single-trade amount |
  |------|-------------|---------------------|
  | Small | `sm` | < ¥200,000 |
  | Medium | `md` | ¥200,000 – ¥2,000,000 |
  | Large | `lg` | ¥2,000,000 – ¥20,000,000 |
  | Extra-large | `elg` | > ¥20,000,000 |
</Tip>

## Example

```python
from asharehub import AShareHub

client = AShareHub(api_key="ash_...")

# Daily money flow breakdown for Ping An Bank over January 2024
df = client.moneyflow(
    symbol="000001.SZ",
    start_date="2024-01-01",
    end_date="2024-01-31",
)

# Compute institutional net inflow (large + extra-large)
df["inst_net"] = (
    (df["buy_lg_amount"] + df["buy_elg_amount"])
    - (df["sell_lg_amount"] + df["sell_elg_amount"])
)

print(df[["trade_date", "net_mf_amount", "inst_net"]])
```
