## Get started in 3 steps

<Steps>
  <Step title="Create your account">
    Visit [asharehub.com/console/register](https://asharehub.com/console/register) and sign up for a free account. The free tier includes 100 API calls per day — no credit card required.
  </Step>
  <Step title="Install the SDK">
    ```bash
    pip install asharehub
    ```
    Requires Python 3.10+ and pandas.
  </Step>
  <Step title="Make your first request">
    ```python quickstart.py
    from asharehub import AShareHub

    client = AShareHub(api_key="ash_your_key_here")
    df = client.market_daily(symbol="000001.SZ", start_date="2024-01-01", end_date="2024-12-31")
    print(df[["trade_date", "open", "high", "low", "close", "vol"]])
    client.close()
    ```
  </Step>
</Steps>

<Note>
  All SDK methods return a `pd.DataFrame`. If the query returns no data, you get an empty DataFrame (`df.empty == True`) rather than an error.
</Note>
