AShareHub gets you from zero to a fully populated `pd.DataFrame` of Chinese A-Share data in just a few lines of Python. Follow the steps below to install the SDK, connect your API key, and run your first queries.

<Steps>

  <Step title="Get your API key">
    Every request to the AShareHub API requires an API key. Visit [asharehub.com/console/register](https://asharehub.com/console/register) to create a free account and generate your key from the dashboard.

    The free tier includes **100 API calls per day** — enough to explore all endpoints and prototype your integration before upgrading.

    <Tip>
      Your API key always starts with `ash_`. Keep it somewhere safe; you'll need it in the next step.
    </Tip>
  </Step>

  <Step title="Install the SDK">
    Install AShareHub from PyPI using pip:

    ```bash
    pip install asharehub
    ```

    **Requirements:** Python 3.10 or later, with `pandas` installed. The package automatically pulls in `httpx` and `pandas` as dependencies, so a fresh install is all you need.
  </Step>

  <Step title="Initialize the client">
    Import `AShareHub` and create a client instance with your API key:

    ```python
    from asharehub import AShareHub

    client = AShareHub(api_key="ash_your_key_here")
    ```

    <Warning>
      Never hard-code your API key directly in source files you plan to share or commit to version control. Use an environment variable instead — see the [Authentication guide](/authentication) for the recommended pattern.
    </Warning>
  </Step>

  <Step title="Fetch daily market data">
    Call `client.market_daily()` to retrieve OHLC price data for any listed A-share. Pass a `symbol` in suffixed format (exchange suffix `.SZ` for Shenzhen, `.SH` for Shanghai), along with optional `start_date` and `end_date` strings in `YYYYMMDD` format:

    ```python
    df = client.market_daily(
        symbol="000001.SZ",
        start_date="20240101",
        end_date="20241231",
    )

    print(df.columns.tolist())
    # ['symbol', 'trade_date', 'open', 'high', 'low', 'close', 'pre_close',
    #  'change', 'pct_chg', 'vol', 'amount']

    print(df[["trade_date", "open", "high", "low", "close", "vol"]].head())
    ```

    Every method in the SDK returns a `pd.DataFrame`, so you can immediately chain pandas operations — filtering, resampling, plotting — without any intermediate parsing.
  </Step>

  <Step title="Close the client">
    When you're done making requests, close the underlying HTTP connection:

    ```python
    client.close()
    ```

    This releases the connection pool managed by `httpx`. For scripts and notebooks where the client lives for the duration of the process, this step is optional but good practice.
  </Step>

</Steps>

## Using the Context Manager

For code that creates and disposes of a client in a single block, use AShareHub as a context manager. The connection closes automatically when the `with` block exits — even if an exception occurs:

```python
from asharehub import AShareHub

with AShareHub(api_key="ash_your_key_here") as client:
    df = client.market_daily(
        symbol="000001.SZ",
        start_date="2024-01-01",
        end_date="2024-12-31",
    )
    print(df.head())
# HTTP connection is closed here automatically
```

## Fetching Real-Time Quotes

Use `client.realtime()` to get the latest intraday snapshot for one or more securities. Pass a single symbol or a comma-separated list of up to 200 symbols:

```python
with AShareHub(api_key="ash_your_key_here") as client:
    df = client.realtime(symbol="600519.SH,000001.SZ")

    print(df[["symbol", "price", "pct_chg", "vol", "trade_time"]])
```

Real-time data includes current price, OHLC, previous close, percentage change, cumulative volume, and the exchange-reported quote timestamp. The endpoint refreshes continuously during trading hours.

<Note>
  All SDK methods return an empty `pd.DataFrame` (where `df.empty == True`) when the API finds no records matching your query — for example, a date range that falls entirely on non-trading days. Always check `df.empty` before downstream processing to avoid errors on empty results.
</Note>
